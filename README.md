## Краткое описание задачи
Разработка консольной процедурной программы на базовом Python для автоматизации учета и анализа данных о заказах интернет-магазина. Программа выполняет чтение данных, валидацию по ТЗ, расчет производных метрик, интерактивный поиск/фильтрацию и экспорт итогового отчета.

## Формат входного файла
Данные считываются из файла `orders.txt` (UTF-8), где каждая непустая строка имеет формат:
`номер_заказа;имя_покупателя;категория_товара;количество;цена;статус`

## Инструкция по запуску
1. Разместите файл `orders.txt` в корневом каталоге рядом со скриптом `main.py`.
2. Запустите скрипт через терминал:
   ```bash
   python main.py
   ```
3. При запуске автоматически выполнятся встроенные тесты `assert`.

## Перечень основных возможностей
* Фильтрация и поиск заказов по статусу, категории или части имени покупателя.
* Составная сортировка: по убыванию стоимости (при равенстве — по возрастанию ID).
* Автоматический расчет выручки только по выполненным заказам.
* Сохранение структурированного отчета с логом ошибок в `orders_report.txt`.

## Перечень обрабатываемых ошибок
1. Отсутствие файла данных на диске (`FileNotFoundError`).
2. Неверное количество полей в строке (не равно 6).
3. Дублирование уникального идентификатора заказа (`order_id`).
4. Пустые значения в обязательных полях (имя покупателя, категория).
5. Некорректный формат чисел или значения за пределами логического диапазона (<= 0).
6. Неизвестный статус заказа.
